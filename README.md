# Starforge — Omarchy theme

Dark violet deep-space theme. Near-black violet-tinted surfaces with a
dark-violet accent (`#7e5af0`).

Ships a single wallpaper: a Gargantua-style black hole on pure black.

## Install

```bash
omarchy theme install https://github.com/gladkyWDSD/omarchy-starforge-theme.git
omarchy theme set starforge
```

## Contents

- `colors.toml` — dark violet palette (dark mode)
- `icons.theme` — Yaru-purple
- `backgrounds/starforge-black-hole.jpg` — black hole wallpaper

Wallpaper: black-hole artwork (wallhaven), darkened + violet-graded.
Terminal, editor and shell extras are generated from `colors.toml` by Omarchy.
